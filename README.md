# 🗂️ FileManager - Custom File Explorer

**A lightweight file explorer that lets you navigate your system with enhanced visibility and usability.**  
Quickly calculate folder sizes and reveal hidden system files that even Windows Explorer ignores.

---

## 🔍 What Makes It Special?

Unlike the default Windows File Explorer, **FileManager** offers:

- 📏 **Instant Folder Size Lookup**  
  See the total size of any folder with a single click — no right-click menus or extra windows.

- 👻 **Reveals Ultra-Hidden Files**  
  Browse system-level files and folders that are invisible even with "Show Hidden Items" enabled in Windows Explorer. Perfect for advanced users and developers.

---

## 🌟 Features

- 🧭 **Clean folder navigation** – Classic tree and pane layout
- 📂 **Quick folder size check** – Just click a button to calculate any folder’s total size
- 👀 **Deep visibility** – Displays system-protected, hidden, and “super-hidden” items
- 🎨 **Minimal UI** – Lightweight and fast, focused on utility
